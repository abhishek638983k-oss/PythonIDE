Program input guide

Enter values separated by spaces or new lines. Each Python input() call reads the next value.

Example input: abhi 23 56 gives abhi, then 23, then 56.

For random values, write /countType, then select Generate:

  • /3n makes 3 integers.
  • /2f makes 2 decimal numbers.
  • /4c makes 4 letters.

Combine values and shortcuts, for example abhi /2n. Generation is manual; running code does not replace shortcuts.

Python IDE Help

Using the IDE

  • Write Python in the editor and select Run. Results and errors appear in Output.
  • For Python input(), enter values in Program input before running. Separate values with spaces or newlines; each call consumes one value. Convert strings when needed, for example age = int(input()).
  • Use the Files list to switch files, or select New Tab to create another Python file. Rename a file with its Rename button or the current-file shortcut.
  • Drag the divider between editor and output to resize the columns. Drag the divider between output and input to resize their heights.
  • Use the Output Clear button to remove output, and Program input Clear to remove queued values without changing code.
  • Undo and Redo change editor history. Format formats the current Python code.
  • Save stores all files in this browser. Auto-save stores edits automatically when enabled. Download exports the current file.
  • Open File loads a local text file into the current editor tab. Share copies a link containing the current code.
  • Install Package installs a Pyodide-compatible package in the current browser session.
  • Switch between GitHub Dark and Light with the theme button. The selected theme is remembered.
  • Select text to reveal a Google search action. In portrait on narrow screens, select the current filename beside the Python logo to open the Files drawer; select the arrow or backdrop to close it.

Random input shortcuts

Write /countType in Program input, then click Generate or press Ctrl+G. Generation only happens when requested; Run never generates values automatically. Shortcuts can be mixed with regular values and each other.

  • n: integer 1–100; f: decimal 0–100 with 2 places; d: decimal 0–100 with 6 places.
  • h: short integer −32,768–32,767; l: integer 1–1,000,000; ll: integer 1–1,000,000,000,000.
  • b: 0 or 1; s: five lowercase letters; c: one lowercase letter.
  • Counts must be 1–1,000. Example: hello /3n /2d /4c generates values in place.
